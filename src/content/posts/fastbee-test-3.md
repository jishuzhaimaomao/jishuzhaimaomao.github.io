# 核心功能测试用例设计

> 用法：用例是模板，先跑手工回归；自动化时把“预期结果”转成断言。

## 1. 账号与权限

| 编号 | 用例 | 前置 | 步骤 | 预期 |
| --- | --- | --- | --- | --- |
| A-01 | 登录成功 | 演示库 | admin/admin123 + 验证码 | 返回 token，能拉取菜单/权限 |
| A-02 | 密码错误 5 次锁定 | user | 连续错误 | 提示锁定 10 分钟 |
| A-03 | 角色菜单差异 | 租户/普通用户 | 登录对比侧边栏 | 只能看到授权菜单/按钮 |
| A-04 | 数据隔离 | 用户 A/B | B 访问 A 的设备列表接口 | 查不到 A 的数据 |
| A-05 | 越权查详情 | 普通用户 | 直接请求他人 deviceId | 返回无权限/空（不允许返回他人数据） |
| A-06 | 注册默认角色 | 新用户 | 注册后查角色 | 自动为普通用户 |

## 2. 产品与物模型

| 编号 | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| P-01 | 新建产品 | 选择分类/JSON/MQTT/直连 | 保存成功、状态未发布 |
| P-02 | 发布前设备认证 | 用产品凭据连接 | 认证被拒（产品未发布） |
| P-03 | 发布产品 | 修改状态为已发布 | 设备可以认证 |
| P-04 | 添加属性 | 温度 decimal -20~120 | 逐条物模型 + things_models_json 同步 |
| P-05 | 添加数组物模型 | RGB arrayCount=3 | 保存后 specs 合法、设备详情能渲染 |
| P-06 | 非法 specs | 类型缺 min/max、enum 空 | 前端校验拦截/后端报错 |
| P-07 | 从模板导入 | 选择模板生成产品 | 物模型与模板一致，产品-模板关联生成 |
| P-08 | 修改/删除物模型 | 已有上报数据 | 确认历史数据保留，新数据按新模型校验 |
| P-09 | 授权码管理 | 产品开启 is_authorize | 无码设备不能认证；错误码被拒；正确码绑定设备 |

## 3. 设备生命周期

| 编号 | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| D-01 | 添加直连设备 | 填名称/产品 | 生成唯一 serialNumber，状态未激活 |
| D-02 | 首次连接激活 | 设备 MQTT CONNECT 成功 | 状态在线，active_time 更新 |
| D-03 | 正常断开 | 设备 DISCONNECT | 状态离线，订阅清理 |
| D-04 | 异常掉线 | 拔网线/断网 | 心跳超时后状态自动离线 |
| D-05 | 重复 clientId | 两台设备同时连接 | 旧连接被踢，新连接在线 |
| D-06 | 禁用设备 | 平台禁用后连接 | CONNACK 拒绝 |
| D-07 | 删除设备 | 删除有日志/任务的设备 | 相关 job、缓存、分享清理 |
| D-08 | 网关+子设备 | 建网关与子设备 | 子设备显示网关关联，可分别管理 |
| D-09 | 设备分享 | 所有者分享给 B | B 只能看到授权模型并可控制（受 sharePerm 约束） |

## 4. 属性/事件上报与存储

| 编号 | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| R-01 | 合法属性上报 | publish JSON 数组 | 详情实时值更新、device_log 新增 |
| R-02 | 未定义 identifier | 上报未知 id | 该条被跳过，不崩溃 |
| R-03 | 类型非法 | temperature="abc" | 校验失败或按容错策略处理（记录异常） |
| R-04 | 事件上报 | event/post | 事件日志新增、前端可见 |
| R-05 | 影子开关 | is_shadow=1 离线下发 | 写 shadow；上线后按设计同步 |
| R-06 | 高频上报 | 每秒 100 条 | Redis 与日志正确、无丢失告警 |
| R-07 | 日志分页/曲线 | 查历史 | 时间倒序、曲线数据点连续 |
| R-08 | 删除设备后数据 | 删除后查询日志 | 日志按策略清理或保留（按业务约定） |

## 5. 指令下发

| 编号 | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| C-01 | 在线设备功能下发 | Web 点“打开开关” | 设备收到 `/function/get` + JSON |
| C-02 | 离线设备下发 | 普通模式 | 记录功能日志（无应答），不误发 |
| C-03 | 影子设备下发 | is_shadow=1 | 走影子，不直接下发 |
| C-04 | 非法 identifier | 下发不存在的功能 | 后端拒绝/忽略 |
| C-05 | 设备回执 | 设备回 `/service/reply` | 日志回执更新（当前源码需二次开发，先记缺陷） |
| C-06 | 定时任务下发 | 建 cron 任务 | 到点触发 publish，日志有记录 |
| C-07 | 场景定时 | 场景+定时触发器 | Quartz job 创建并可按 cron 触发 |

## 6. 规则脚本

| 编号 | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| S-01 | 数据流改写 | 对象 JSON 转数组脚本 | 平台按新 payload 入库 |
| S-02 | 脚本错误 | 语法错误/抛异常 | 不阻塞后续消息，日志有 error |
| S-03 | 停用脚本 | enable=0 | 消息直接走原逻辑 |
| S-04 | 多脚本顺序 | script_order 不同 | 按顺序执行 |
| S-05 | 设备上下线事件 | event=3/4 脚本 | 正确触发 |

## 7. 视频模块（协议级手工/模拟器）

| 编号 | 用例 | 步骤 | 预期 |
| --- | --- | --- | --- |
| V-01 | SIP 注册 | 模拟器/摄像头注册 | 设备上线、目录/通道入库 |
| V-02 | 通道上线 | 设备上报目录 | 通道树/状态正确 |
| V-03 | 实时播放 | 前端点预览 | INVITE→推流→播放成功 |
| V-04 | 云台控制 | PTZ 上/下/左/右/缩放 | 设备收到 Control 命令 |
| V-05 | 设备离线 | 模拟器停止 | 通道/设备离线状态正确 |
| V-06 | 媒体服务器失联 | 停 ZLMediaKit | 拉流失败提示明确，不影响 MQTT 业务 |

## 8. 系统管理

复用若依成熟能力，至少回归：用户/角色授权、菜单动态加载、字典、参数、操作日志、登录日志、在线用户强退、通知公告（XSS 净化）、定时任务白名单。

## 9. 用例优先级汇总

快速回归（30 分钟内）建议 = A-01/A-04 + P-02/P-03 + D-01/D-02/D-05 + R-01/R-02 + C-01/C-02 + S-02。

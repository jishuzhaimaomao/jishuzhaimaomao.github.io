# FastBee 开源物联网平台学习文档

> 生成日期：2026-09-08  
> 面向对象：希望系统学习 FastBee 的业务、架构、源码与测试的开发者  
> 覆盖范围：仓库内 `springboot` 后端、`vue` Web 管理端、`docker` 部署资源、`images` 图片资源

## 一、这是什么

FastBee 是一个面向中小企业与个人开发者的**轻量、全栈、可二次开发**的开源物联网（IoT）平台。平台基于若依（RuoYi-Vue）脚手架和 Spring Boot 构建，特点是**内置自研 Netty MQTT Broker**，不需要额外部署 EMQX 等独立 MQTT 服务端，同时提供产品/设备/物模型管理、数据监控、规则引擎、视频接入（GB28181/SIP）、多端应用与 Docker 一键部署能力。

仓库当前版本信息：

| 项目 | 说明 |
| --- | --- |
| 仓库版本 | `2.1.0`（pom 中 `fastbee.version`） |
| 后端 | Spring Boot `2.5.15`、Java 8、MyBatis-Plus、Spring Security、JWT |
| Web 端 | Vue `2.6.12` + Element-UI、Vuex、Vue Router、Axios、ECharts、MQTT.js |
| 数据库 | MySQL 为主；SQL 还提供 PostgreSQL、SQL Server、Oracle、达梦版本 |
| 时序库 | TDengine / InfluxDB / IoTDB / MySQL 可切换 |
| 协议 | MQTT（Netty 自研 Broker + MQTT over WebSocket）、GB28181(SIP)；协议编解码可扩展 |
| 目录规模 | Java 源码约 890 个文件、Vue 视图约 160 个、MyBatis XML 约 53 个 |
| 开源协议 | AGPL-3.0 |

## 二、仓库结构速览

```text
FastBee/
├── springboot/        # Java 后端（Maven 多模块）
├── vue/               # Web 管理端（RuoYi-Vue 演进）
├── docker/            # 容器化部署资源（docker-compose、镜像数据目录）
├── images/            # README 展示图片
├── 学习文档/          # 本文档集
├── README.md          # 项目中文介绍
├── README.en.md       # 英文介绍
└── RoadMap.md         # 官方规划（架构/功能/SDK/社区路线）
```

注意：仓库本身不包含**移动端 uniapp**与**硬件 SDK** 源码，它们分别托管在官方其他仓库（见 README 中的 `fastbee-app`、`fastbee-sdk`）。本文档以本仓库代码为准。

## 四、使用约定

- 文中的源码路径如 `springboot/fastbee-server/mqtt-broker/...` 均相对于仓库根目录，即当前目录的上一级 `..`。
- 业务表中的“菜单”来自初始化 SQL `springboot/sql/fastbee.sql` 中 `sys_menu` 的种子数据。
- 文档中的分析结论以仓库当前 `master` 分支代码为准；个别模块（如 OTA）只有接口与周边代码、核心升级下发仍未完成，文档会明确标注，避免误导。
- 默认端口与账号仅适用于本地开发/官方演示；生产环境请务必按第 12 篇修改密码与配置。
